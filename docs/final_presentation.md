# EconoCausal – Final Presentation Notes

## Project Overview
EconoCausal focuses on personalized dynamic pricing using Double Machine Learning to identify the most profitable discount for each customer.

## Dataset
- Synthetic retail dataset
- 100,000 customer records
- 15 features
- Discount levels: $0, $10 and $20
- Target variable: Purchase

## Dashboard
- Developed using Streamlit and Plotly.
- Displays estimated purchase probabilities and expected profits.
- Shows customer-level recommended discounts.
- Visualizes discount distribution and estimated business impact.

## Key Results
- $20 recommended for 75.9% of customers.
- $10 recommended for 21.4% of customers.
- $0 recommended for 2.7% of customers.
- Estimated average profit increased from $181.46 to $237.43.
- Estimated improvement: 30.8%.

## Conclusion
The dashboard converts causal model outputs into personalized pricing recommendations and meaningful business insights.
